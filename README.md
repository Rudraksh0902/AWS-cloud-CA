# ChatGPT-Inspired Chat Interface

A ChatGPT-inspired conversational interface built using **HTML, CSS, and JavaScript**. This project focuses on recreating a clean, dark-themed AI chat experience while learning frontend web development.

## ✨ Features

- **Dark-themed UI** inspired by modern AI chat applications
- **Chat interface** with user and AI message bubbles
- **Sidebar** for chat history and navigation
- **New Chat** functionality
- **Dynamic message rendering** using JavaScript
- **Responsive layout** for a clean user experience

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling, layout, and visual design
- **JavaScript (Vanilla JS)** — Chat interactions and dynamic UI updates

## 📁 Project Structure

```text
chatgpt-frontend/
├── index.html
├── style.css
└── script.js
```

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/chatgpt-frontend.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, open the folder in Visual Studio Code and use the **Live Server** extension for local development.
